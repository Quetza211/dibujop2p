Privacy Policy
Last updated: August 30, 2026
This privacy policy governs the use of the Dibuja2P2 application for Android devices, developed by Azael Martínez (Quetza).
What information do we collect? For the basic operation of the game and its online modes, the application collects and processes the following data:
•	User profile: A username chosen by the player, which is stored locally on the device. Optionally, the user can add a profile picture. This information (name and image) is only shared temporarily with the opponent during an active online match.
•	Connection data: Internal device identifiers (anonymous IDs) and IP addresses necessary to establish a direct connection between players over the internet.
Information and drawing storage
•	Solo mode and gallery: Incomplete drawings, as well as images exported in .png format, are stored solely and exclusively locally in the memory of the user's device. The application has an internal gallery that only has access to images created within the game.
•	Manual export: The user has the option to export drawings (created in solo or multiplayer matches) to their local photo gallery. The application does not extract or read other personal images from the device.
Multiplayer Mode and Connections (Friends and Random) The game allows online matches using room codes (with friends) or random matchmaking (with strangers).
•	Direct Connection (P2P via WebRTC): During the match, drawing strokes and game data are transmitted directly between players' devices using WebRTC technology. This information travels encrypted and is not permanently stored on external servers.
•	Moderation and Filters: To protect the user experience, the application implements automatic filters that detect and replace profanity or offensive words in usernames with asterisks (*****). Additionally, Google ML Kit technology is used for the automatic analysis and moderation of profile pictures in order to prevent the display of inappropriate content.
Use of third-party services The application uses third-party services that may collect information for its proper functioning:
•	Connection and Database Services (Google Firebase): Used exclusively as a signaling server to facilitate player matchmaking and manage the initial connection of online matches.
•	Image Moderation (Google ML Kit): Used to analyze the content of profile pictures locally or in the cloud to ensure a safe environment.
•	Advertising (Google AdMob): The application displays ads. This service may collect limited data such as approximate location (network-based), device type, and interactions with ads. This data is managed directly by Google and its partners.
Cookies and advertising Third-party vendors, including Google, use technologies similar to cookies or advertising identifiers to show ads based on a user's prior visits to this or other applications. You can learn more about Google AdMob policies at: https://support.google.com/admob/answer/6128543?hl=es-419
Changes to this policy Any changes to this Privacy Policy will be notified through an update within the application, indicating the date of the last modification.
